# i18n PT/EN/ES Implementation Plan — Fatia 4/4 pré-APK

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans para implementar este plan task-a-task, com gate de validação entre tasks (analyze + testes + inspeção anti-drift), conforme diretiva do dono nas fatias anteriores.

**Goal:** Todas as strings de UI do app em PT/EN/ES via `gen-l10n` (.arb), com o seletor de idioma existente trocando o app inteiro em runtime e persistindo.

**Architecture:** Infra `l10n.yaml` + 3 `.arb` gerando `AppLocalizations` em `lib/l10n/` (source tree). Locale = fonte única JÁ EXISTENTE (`SettingsController.language`, persistido) — NÃO criar controller novo (evita estado duplicado; memória `raro-pattern-single-source-of-truth-persisted-settings`). `MaterialApp.locale` passa a ler `settings.language`; `language` vira anulável (`null` = seguir locale do sistema, resolução automática do Flutter contra `supportedLocales`).

**Tech Stack:** Flutter 3.44.0 gen-l10n (validado no binário 2026-07-18), `intl ^0.20.2`, `flutter_localizations` (já no pubspec com `generate: true`).

## Global Constraints

- Wake word/marca **"Raro"/"RARO"** NUNCA traduzida nem alterada (ADR-0009; hook block-forbidden-terms ativo).
- **NÃO usar `synthetic-package` no `l10n.yaml`** — flag REMOVIDA na 3.44 (`--help`: "DEPRECATED. This flag cannot be enabled and should be removed"; provado no binário local 2026-07-18). A memória `raro-pattern-flutter-i18n-synthetic-package-false` será atualizada no fechamento.
- Free trial **30 dias**, planos **R$ 9,90 / R$ 89,90** — valores vêm de `raro_shared`, nunca hardcoded no .arb.
- Commits Conventional (subject lowercase, ≤100 chars, scope do enum; i18n usa scope da feature tocada ou `mobile`).
- Sem comentários em código de produção; imports absolutos `package:raro_mobile/...`.
- Entre CADA task: `bun run --filter '@raro/mobile' analyze` + `bun run --filter '@raro/mobile' test` verdes + inspeção anti-drift antes do commit.
- Traduções EN/ES autoradas na migração e listadas em tabela PT→EN→ES no corpo do PR para revisão do dono (DoD §5 da spec).
- Harness de debug (`camera_test_harness_screen.dart`) FORA do i18n (não é UI de produção).

## Fontes da verdade

- Spec: `docs/superpowers/specs/2026-07-17-i18n-pt-en-es-design.md` (aprovada pelo dono).
- Desvios da spec, ambos previstos/motivados por ela:
  1. §2.1 "A validar no plan": `synthetic-package` — resolvido: OMITIR a chave (removida na 3.44).
  2. §2.3 `localeControllerProvider` novo — substituído pelo `SettingsController` existente, que JÁ persiste `language` e JÁ recebe writes do `LanguageGrid` (verificado em `settings_controller.dart:41`, `recording_settings_codec.dart:11`, `settings_screen.dart:149-151`). Criar um segundo controller seria o enum/estado duplicado que a memória de settings proíbe. A INTENÇÃO da spec ("fonte única persistida via mecanismo existente") é cumprida com menos código.
